01

coderaven's workflow

coderaven shells out to your existing Claude Code install, asks for a structured review of the diff, persists it as JSON, and brings up a local viewer. No daemons to manage, no credentials to configure beyond what claude already needs.

1

Read the diff

git diff base...HEAD against your detected base branch (origin/main, master, or whatever you specify with --base).

2

Ask claude

Pipes the diff plus a strict prompt schema to claude -p. The model returns comments with file paths, line ranges, severity, and suggested replacements.

3

Persist + serve

Writes the result to .coderaven/reviews/<branch>-<unix>.json, spawns the viewer on :6677, opens your browser.

02

coderaven's reviews viewer

The viewer renders each finding as a GitLab-style thread: the actual changed code with line numbers, the comment beneath it, a unified-diff suggested change, and your team's replies. Resolve a thread to dim it; reply to keep the conversation in-band.

03

What coderaven offers? Five things, no more.

coderaven is deliberately small. It does the review loop and gets out of the way. No dashboard, no auth server, no SaaS account.

Structured findings

Each comment has filepath, line range, severity, category, message, and a concrete suggested replacement. Strict JSON schema, validated and parsed.

Git-syncable

Reviews live in .coderaven/reviews/*.json. Commit the folder, your teammate pulls the branch and sees the same threads — replies, resolves, and all.

Inline diff viewer

Local web UI at :6677: file header, the changed code with line numbers, comment beneath, suggested change as a unified diff. Live-updated via SSE.

Resolve & reply

One click resolves a thread. Reply with your git config user.name as the author, persisted into the same JSON file. No external services.

Custom rules

Drop a .coderaven/config.json with extraRules and the model gets your project conventions appended to every review.

04

Get Started

Requires Node 18+, git, and an authenticated Claude Code install. Everything else is self-contained. 

# Install from npm
npm install -g coderaven

# instead, to clone & build
git clone https://github.com/adithyavis/coderaven.git
cd coderaven
npm install
npm run build
npm link

# confirm
coderaven --version

# run a review on any branch ahead of main
cd ~/your-project
git checkout feat/something
coderaven review

# open the viewer if it isn't already
open http://localhost:6677
